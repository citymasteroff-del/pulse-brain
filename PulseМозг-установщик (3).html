Pulse Мозг

Всё приложение внутри этого файла — 115 КБ. Распакуй и ставь на телефон.

Шаг 1 · Распаковка

Достать файлы

Открой этот файл на компьютере в Chrome и жми кнопку. Файлы упадут в «Загрузки».

Шаг 2 · Хостинг

Залить на GitHub Pages

Бесплатно и навсегда. Нужен один раз, дальше только обновляешь.

  1. Регистрация на github.com → кнопка + → New repository
  2. Имя pulse-brain, тип Public → Create
  3. Add file → Upload files → перетащи все 6 файлов (кроме .md) → Commit
  4. Settings → Pages → Branch: main, папка /(root) → Save
  5. Через минуту появится адрес https://логин.github.io/pulse-brain/
Шаг 3 · Установка

Поставить на Андроид

Открой свою ссылку в Chrome на телефоне — именно в Chrome, не в ватсапе.

  1. Меню (три точки) → Установить приложение
  2. Иконка появится на рабочем столе, запуск без адресной строки
  3. В приложении: Настройки → вставь URL Гугл Таблицы → Проверить связь
  4. ⬇ Загрузить из таблицы — диалоги приедут на телефон
Правило синхронизации: закончил на телефоне — жми ⬆ Выгрузить базу. Сел за компьютер — ⬇ Загрузить из таблицы. Пять секунд, зато ничего не потеряется.
Хочешь настоящий APK

Собрать файл .apk

Бесплатный сервис соберёт APK из твоей ссылки за пару минут — можно ставить как обычное приложение и раздавать менеджерам.

  1. Сделай Шаги 1–2, чтобы появилась ссылка на GitHub Pages
  2. Зайди на pwabuilder.com, вставь свою ссылку → Start
  3. Выбери Android → Generate Package
  4. Скачается архив, внутри app-release-signed.apk
  5. Перекинь APK на телефон → открой → разреши «установку из неизвестных источников»
APK удобнее раздавать сотрудникам, но обновлять придётся вручную. PWA обновляется само при заливке новой версии на GitHub — для себя проще она.
Мозг считает без интернета: продающие фразы, фразы-убийцы, оценка клиента. Сеть нужна только для синхронизации с таблицей.
